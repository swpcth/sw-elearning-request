# ระบบคำร้องขอนำหน่วยคะแนน E-Learning มาใช้ทดแทน

เว็บฟอร์มสำหรับผู้ประกอบวิชาชีพยื่นคำร้อง + ระบบให้เจ้าหน้าที่ค้นหาผู้ยื่นคำร้องจากชื่อ-นามสกุล
ใช้ **Google Sheets** เป็นฐานข้อมูล (ผ่าน Google Apps Script เป็น backend/API) และโฮสต์หน้าเว็บด้วย **GitHub Pages**

```
index.html            → แบบฟอร์มสาธารณะ สำหรับผู้ยื่นคำร้อง
admin.html            → หน้าเจ้าหน้าที่ ค้นหา/ตรวจสอบ/อัปเดตสถานะคำร้อง (⚠️ ไม่มีรหัสผ่านป้องกัน — ดูหัวข้อความปลอดภัยด้านล่าง)
config.js             → จุดเดียวที่ต้องตั้งค่า URL ของ backend
style.css             → สไตล์หน้าเว็บ
logo.png              → ตราสภาวิชาชีพสังคมสงเคราะห์ (แสดงบนหัวกระดาษทั้ง 2 หน้า)
thai-address.json     → ข้อมูลจังหวัด/อำเภอ/ตำบล/รหัสไปรษณีย์ทั้งประเทศ (ใช้ทำ dropdown ที่อยู่)
apps-script/Code.gs   → โค้ด backend ที่ต้องนำไปวางใน Google Apps Script
```

> ไฟล์ทั้งหมด (ยกเว้นโฟลเดอร์ `apps-script/`) ต้องอยู่ที่ **root ของ repository** — ห้ามอยู่ในโฟลเดอร์ย่อย
> เพราะหน้าเว็บอ้างอิงไฟล์เหล่านี้ด้วย path ตรง ๆ เช่น `style.css`, `logo.png`, `thai-address.json`

## ขั้นตอนที่ 1 — สร้างฐานข้อมูล (Google Sheet + Apps Script)

1. ไปที่ [sheets.google.com](https://sheets.google.com) แล้วสร้างสเปรดชีตใหม่ (ว่าง ๆ ก็ได้ ไม่ต้องตั้งหัวตารางเอง สคริปต์จะสร้างให้)
   ตั้งชื่อไฟล์ เช่น `SW-ELearning-Requests-DB`
2. คัดลอก **Spreadsheet ID** จาก URL ของชีต เช่นจาก
   `https://docs.google.com/spreadsheets/d/XXXXXXXXXXXX/edit`
   ให้คัดลอกส่วน `XXXXXXXXXXXX` (ระหว่าง `/d/` กับ `/edit`)
3. เปิด [script.google.com](https://script.google.com) แล้วสร้างโปรเจกต์ Apps Script ใหม่ (หรือจะเปิดผ่าน **Extensions > Apps Script** จากในชีตก็ได้เหมือนกัน)
   ลบโค้ดเดิมในไฟล์ `Code.gs` ทั้งหมด แล้วคัดลอกเนื้อหาจากไฟล์ `apps-script/Code.gs` ในโปรเจกต์นี้ไปวางแทน
4. แก้บรรทัดนี้:
   ```js
   const SHEET_ID  = 'PASTE_YOUR_SPREADSHEET_ID_HERE'; // Spreadsheet ID จากข้อ 2
   ```
5. กด **Deploy > New deployment**
   - คลิกไอคอนเฟือง เลือกประเภทเป็น **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด **Deploy** แล้วอนุญาตสิทธิ์ (Authorize access) ตามที่ระบบขอ
6. คัดลอก **Web app URL** ที่ได้ (รูปแบบ `https://script.google.com/macros/s/xxxx/exec`) เก็บไว้ใช้ในขั้นตอนถัดไป

> หมายเหตุ: ทุกครั้งที่แก้โค้ดใน Apps Script แล้วต้องการให้มีผลกับเว็บจริง ให้กด **Deploy > Manage deployments > แก้ไข (ไอคอนดินสอ) > New version > Deploy** ใหม่ (URL เดิมจะยังใช้ได้)

### ตั้งค่าหน้าตาชีตอัตโนมัติ (Setup)

หลังวางโค้ดและตั้งค่า `SHEET_ID` แล้ว ให้รันฟังก์ชัน `setupSheet` ครั้งเดียว:

- ในหน้า Apps Script editor เลือกฟังก์ชัน **`setupSheet`** จากดรอปดาวน์ด้านบน (ข้าง ▶ เรียกใช้)
  แล้วกด **▶ เรียกใช้** ครั้งแรกจะมีป๊อปอัพขอสิทธิ์ (Authorize) เพิ่มเติม กด "Allow"/"อนุญาต" ได้ตามปกติ
- ระบบจะ:
  - สร้างชีต "Requests" พร้อมหัวตารางที่ถูกต้อง (ถ้ายังไม่มี)
  - จัดฟอร์แมตหัวตาราง ปรับความกว้างคอลัมน์ให้อ่านง่าย
  - ตั้งคอลัมน์ NationalId และ LicenseNo เป็นข้อความ (Plain text) เพื่อไม่ให้ตัดเลข 0 นำหน้าออก
  - ใส่ dropdown ให้คอลัมน์ Status เลือกได้เฉพาะ "รอดำเนินการ / อนุมัติ / ไม่อนุมัติ"
  - ใส่สีไฮไลต์ตามสถานะ (เขียว/เหลือง/แดง) อัตโนมัติ
- ดูผลลัพธ์ได้ที่ "บันทึกการดำเนินการ" (Execution log) ด้านล่าง หรือเปิดชีตขึ้นมาดูตรง ๆ เลยก็ได้

รันซ้ำได้เรื่อย ๆ โดยไม่ลบข้อมูลเดิม

> หากสร้าง Apps Script ผ่าน **Extensions > Apps Script** จากในตัวชีตโดยตรง (ไม่ได้สร้างแยกที่ script.google.com)
> ระบบจะมีเมนู **"ระบบคำร้อง E-Learning"** ขึ้นในแถบเมนูของชีตให้กดรันได้เลยโดยไม่ต้องเปิด Apps Script editor

## ขั้นตอนที่ 2 — ตั้งค่าเว็บให้เชื่อมกับ backend

เปิดไฟล์ `config.js` แล้วแก้บรรทัดเดียว:

```js
const APPS_SCRIPT_URL = "https://script.google.com/macros/s/xxxxxxxx/exec";
```

วาง URL ที่คัดลอกมาจากขั้นตอนที่ 1 แทนที่ `PASTE_YOUR_WEB_APP_URL_HERE`

## ขั้นตอนที่ 3 — ขึ้นเว็บด้วย GitHub Pages

1. สร้าง repository ใหม่บน GitHub (public หรือ private ก็ได้ ถ้า private ต้องมี GitHub Pro ถึงจะเปิด Pages ได้)
2. อัปโหลดไฟล์เหล่านี้ขึ้น **root** ของ repository (ไม่ใส่ในโฟลเดอร์ย่อย):
   `index.html`, `admin.html`, `config.js`, `style.css`, `logo.png`, `thai-address.json`
   - จะใช้ GitHub Desktop, `git push`, หรือลากไฟล์วางในหน้าเว็บ GitHub ก็ได้
   - ไม่ต้องอัปโหลดโฟลเดอร์ `apps-script/` ก็ได้ (เป็นแค่โค้ดสำรองไว้ดู ไม่ได้ใช้รันบนเว็บ) แต่เก็บไว้ใน repo ก็ไม่มีปัญหา
3. ไปที่ **Settings > Pages**
   - Source: **Deploy from a branch**
   - Branch: เลือก `main` (หรือ branch ที่ใช้) และโฟลเดอร์ `/ (root)`
   - กด **Save**
4. รอสักครู่ GitHub จะแสดง URL เว็บไซต์ เช่น
   `https://<username>.github.io/<repo-name>/`

- แบบฟอร์มสำหรับผู้ยื่นคำร้อง: `https://<username>.github.io/<repo-name>/`
- หน้าเจ้าหน้าที่: `https://<username>.github.io/<repo-name>/admin.html`

## การใช้งาน

### ผู้ยื่นคำร้อง (index.html)
กรอกข้อมูลผู้ยื่น (รวมเลขบัตรประชาชน, วันที่ออก/หมดอายุใบอนุญาตแบบ พ.ศ., และที่อยู่แบบเลือกจังหวัด/อำเภอ/ตำบล) แล้วกด "ยื่นคำร้อง"
ระบบจะบันทึกแถวใหม่ลง Google Sheet โดยอัตโนมัติพร้อมสถานะเริ่มต้น "รอดำเนินการ"
และแสดง **เลขที่คำร้อง** ให้ผู้ยื่นเก็บไว้อ้างอิง

### เจ้าหน้าที่ (admin.html)
1. พิมพ์ชื่อ, นามสกุล หรือ เลขที่ใบอนุญาต (พิมพ์บางส่วนก็ค้นเจอ) แล้วกดค้นหา — ผลลัพธ์เรียงจากคำร้องล่าสุดไปเก่าสุด
2. คลิกแถวเพื่อดูรายละเอียด ปรับสถานะเป็น "อนุมัติ" / "ไม่อนุมัติ" / "รอดำเนินการ" ใส่หมายเหตุ แล้วกดบันทึก
   — ข้อมูลจะอัปเดตกลับไปที่ Google Sheet ทันที

> **หมายเหตุ:** สถานะเริ่มต้นของทุกคำร้องคือ **"รอดำเนินการ"** เสมอ (ระบบตั้งให้อัตโนมัติตอนยื่นคำร้อง)
> ถือเป็นค่าปกติ หมายถึง "ยังไม่ได้รับการพิจารณา" — เจ้าหน้าที่ค่อยเปลี่ยนเป็น "อนุมัติ" หรือ "ไม่อนุมัติ" เองภายหลัง

## โครงสร้างข้อมูลใน Google Sheet (ชีต "Requests")

| คอลัมน์ | ความหมาย |
|---|---|
| ID | เลขที่คำร้อง (สร้างอัตโนมัติ) |
| Timestamp | วันเวลาที่ยื่นคำร้อง |
| Prefix / FirstName / LastName | คำนำหน้า (รวมกรณี "อื่น ๆ" ที่ระบุเอง) / ชื่อ / นามสกุล |
| NationalId | เลขประจำตัวประชาชน 13 หลัก |
| LicenseNo | เลขที่ใบอนุญาต |
| IssueDate / ExpiryDate | วันที่ออก / วันหมดอายุใบอนุญาต รูปแบบ วว/ดด/ปปปป แบบ **พ.ศ.** (เช่น 10/01/2563) |
| AddressDetail | บ้านเลขที่ / หมู่ / ซอย / ถนน (กรอกเอง) |
| Province / District / Subdistrict / PostalCode | จังหวัด / อำเภอ / ตำบล / รหัสไปรษณีย์ (เลือกจาก dropdown, รหัสไปรษณีย์เติมอัตโนมัติ) |
| Phone / Email | ข้อมูลติดต่อ (บังคับกรอกทั้งคู่) |
| Status | รอดำเนินการ / อนุมัติ / ไม่อนุมัติ |
| StaffNote | หมายเหตุจากเจ้าหน้าที่ |
| UpdatedAt | วันเวลาที่เจ้าหน้าที่แก้ไขล่าสุด |

คุณสามารถเปิด Google Sheet นี้ดูข้อมูลดิบ กรอง หรือทำรายงานเพิ่มเติมได้ตามปกติ

## ข้อควรระวังด้านความปลอดภัย

- **⚠️ หน้าเจ้าหน้าที่ (`admin.html`) ไม่มีรหัสผ่านป้องกันแล้ว** ใครก็ตามที่รู้ลิงก์ (`https://<username>.github.io/<repo>/admin.html`)
  จะค้นหาและแก้ไขสถานะคำร้องได้ทั้งหมดทันที โดยไม่ต้องล็อกอิน
- ข้อมูลที่ยื่นเป็นข้อมูลส่วนบุคคล (PII) รวมถึงเลขบัตรประชาชน — **อย่าเผยแพร่ลิงก์ `admin.html` ต่อสาธารณะ**
  ส่งให้เฉพาะเจ้าหน้าที่ที่เกี่ยวข้องเท่านั้น และตั้งค่าการแชร์ Google Sheet ให้จำกัดเฉพาะผู้ที่เกี่ยวข้องด้วย
- หากต้องการความปลอดภัยเพิ่มเติมในอนาคต แนะนำให้พิจารณา:
  - นำระบบรหัสผ่าน/PIN กลับมาใช้ (โค้ดเดิมมีให้อ้างอิงในประวัติการแก้ไข)
  - หรือใช้ Google Sign-In / OAuth ตรวจสอบตัวตนเจ้าหน้าที่ก่อนเข้าถึงข้อมูล
  - หรือจำกัด "Who has access" ของ Apps Script Web app ให้เฉพาะผู้ใช้ในองค์กร (ต้องมี Google Workspace)
